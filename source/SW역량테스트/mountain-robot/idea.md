## 문제 요약

높이가 적힌 N x N 격자에서 왼쪽 위에서 오른쪽 아래까지 상하좌우로 이동하며 쓰는 에너지의 최솟값을 구합니다.

이 풀이는 원문의 이동 비용을 확인하지 못해 학습용 모델을 가정했습니다. 내리막은 0, 평지는 1, 오르막은 높이 차이의 2배입니다. 입력은 T, 각 테스트의 N, 높이 N x N개이고 출력은 `#번호 최소 에너지`입니다. 보급로와 비슷한 최단경로 유형이라는 정보만 확인했으므로 실제 비용 규칙이 다르면 이동 비용을 계산하는 함수만 바꾸면 됩니다.

## 발상

1. 칸을 정점으로, 인접 칸으로 가는 이동을 방향이 있는 간선으로 봅니다. 비용이 모두 0 이상인 최단경로 문제입니다.
2. 지나는 칸 수가 적은 길이 항상 싸지는 않습니다. 내리막으로 돌아가는 길이 더 쌀 수 있어 BFS로는 부족합니다.
3. 거리 배열을 큰 값으로 채우고 출발 칸을 0으로 둔 뒤 우선순위 큐에 넣고 비용이 작은 칸부터 꺼냅니다.
4. 꺼낸 비용이 거리 배열의 값과 다르면 더 좋은 경로가 이미 있다는 뜻이므로 건너뜁니다.
5. 네 방향 이웃에 대해 지금 비용에 이동 비용을 더한 값이 거리 배열보다 작으면 갱신하고 큐에 넣습니다.
6. 도착 칸이 큐에서 처음 꺼내질 때의 비용이 답입니다.

## 놓치기 쉬운 점

- 오르막과 내리막의 비용이 달라서 A에서 B로 가는 비용과 B에서 A로 가는 비용이 다릅니다. 간선에 방향이 있다고 생각해야 합니다.
- 출발 칸에는 들어가는 비용이 없습니다.
- 규칙에 따라 비용 합이 커질 수 있어 거리와 큐의 비용은 long으로 다룹니다.
- 칸을 큐에 넣는 순간이 아니라 꺼내는 순간에 최소 비용이 확정됩니다.

## 복잡도와 검증

정점이 N^2개이고 간선이 최대 4N^2개라 시간 O(N^2 log N), 공간 O(N^2)입니다.

가정한 비용 규칙의 예제와 경계 사례로 확인했습니다. 원문 조건과는 대조하지 못했습니다.
