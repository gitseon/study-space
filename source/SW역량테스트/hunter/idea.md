## 문제 요약

격자에 몬스터와 고객이 있습니다. 양수는 몬스터 번호, 음수는 같은 번호 고객이고 몬스터는 최대 4마리입니다. 왼쪽 위 칸에서 출발해 모든 몬스터를 잡고 모든 고객을 방문하는 최소 이동 거리를 구합니다. 고객은 같은 번호 몬스터를 먼저 잡은 뒤에만 방문할 수 있습니다.

입력은 T, 각 테스트의 N, N x N 격자이고 출력은 `#번호 최소 거리`입니다.

## 발상

1. 격자는 크지만 몬스터가 최대 4마리라 방문할 지점은 최대 8곳입니다. 순서를 모두 시도하는 완전탐색을 떠올립니다.
2. 장애물이 없는 격자에서 두 지점 사이의 이동 거리는 맨해튼 거리입니다. 길을 찾는 BFS는 필요 없습니다.
3. 몬스터를 잡았는지와 고객을 방문했는지는 서로 다른 상태라 배열을 둘로 나눕니다.
4. DFS의 인자는 현재 위치와 지금까지 방문한 지점 수와 누적 거리입니다. 다음 후보는 아직 잡지 않은 몬스터이거나 이미 잡았지만 방문하지 않은 고객입니다.
5. 후보를 고를 때마다 상태를 표시하고 재귀 호출 뒤에 원래대로 되돌립니다.
6. 누적 거리가 지금까지의 최솟값 이상이면 더 탐색해도 나아지지 않으므로 가지치기합니다. 지점을 모두 방문하면 최솟값을 갱신합니다.

## 놓치기 쉬운 점

- 입력을 읽을 때 몬스터가 나올 때마다 개수를 세어야 합니다. 세지 않으면 탐색이 곧바로 끝나 항상 0을 출력합니다.
- 고객 번호는 음수라 인덱스로 쓰려면 부호를 바꿔야 합니다.
- 테스트마다 위치 배열, 방문 배열, 몬스터 수, 정답의 초기값을 다시 만들어야 합니다.
- 고객 방문 후보는 방금 잡은 몬스터의 고객만이 아닙니다. 이미 잡아 두었지만 아직 방문하지 않은 모든 고객이 후보입니다.

## 복잡도와 검증

방문 순서는 몬스터가 M마리일 때 최대 `(2M)! / 2^M`가지이고 M이 4이면 2520가지입니다. 고객은 반드시 자기 몬스터 뒤에 와야 하므로 전체 순열의 절반이 쌍마다 걸러집니다.

작은 격자 40개를 가능한 모든 방문 순서를 따져 본 결과와 비교해 확인했습니다.
