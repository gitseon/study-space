## 문제 요약

학생이 N명 있고 두 학생의 키를 비교한 결과 M개가 주어집니다. a가 b보다 작다는 정보입니다. 비교 결과만으로 자신의 키 순서를 정확히 알 수 있는 학생이 몇 명인지 구합니다.

입력은 T, 각 테스트의 N, M, 비교 결과 M줄이고 출력은 `#번호 학생 수`입니다. 같은 아이디어의 2458번 문제는 테스트 수 T가 없는 형식입니다.

## 발상

1. `reachable[a][b]`를 a가 b보다 작다는 사실을 직접 또는 간접으로 안다는 뜻으로 둡니다. 입력 `a b`마다 `reachable[a][b]`를 참으로 표시합니다.
2. a가 via보다 작고 via가 b보다 작으면 a는 b보다 작습니다. 이 추이 관계를 플로이드–워셜로 모든 쌍에 퍼뜨립니다.
3. 경유 학생 via를 가장 바깥 반복문에 둡니다. via 단계가 끝나면 1번부터 via번 학생만 거쳐 가는 모든 관계가 반영됩니다.
4. 학생마다 다른 학생과의 관계를 하나라도 알면 셉니다. `reachable[s][other]` 또는 `reachable[other][s]`가 참이면 아는 관계입니다.
5. 아는 관계가 N-1개인 학생이 순서를 아는 학생입니다.

## 놓치기 쉬운 점

- 반복문 순서가 핵심입니다. 시작, 경유, 도착 순서로 쓰면 1 < 3, 3 < 2, 2 < 4일 때 1 < 4를 놓칩니다.
- `reachable[from][via]`가 거짓이면 via를 거쳐 갈 수 없으므로 도착 반복을 건너뛰어 시간을 줄입니다.
- 두 방향을 모두 확인해야 합니다. 나보다 큰 관계만 세면 작은 학생과의 관계를 빠뜨립니다.
- 자기 자신과의 관계는 세지 않습니다.

## 복잡도와 검증

플로이드–워셜이 O(N^3)이고 정답 확인이 O(N^2)이라 전체 O(N^3)입니다. 관계 행렬 때문에 공간은 O(N^2)입니다.

BFS 풀이와 같은 무작위 그래프 40개와 관계를 늦게 발견하는 사례로 확인했습니다. 반복문 순서가 잘못된 플로이드–워셜은 그 사례에서 답이 달라집니다.
