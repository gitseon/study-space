## 문제 요약

학생이 N명 있고 두 학생의 키를 비교한 결과 M개가 주어집니다. a가 b보다 작다는 정보입니다. 비교 결과만으로 자신의 키 순서를 정확히 알 수 있는 학생이 몇 명인지 구합니다.

입력은 T, 각 테스트의 N, M, 비교 결과 M줄이고 출력은 `#번호 학생 수`입니다. 같은 아이디어의 2458번 문제는 테스트 수 T가 없는 형식입니다.

## 발상

1. 학생 s의 순서를 알려면 s보다 작은 학생 전부와 큰 학생 전부를 직접 또는 간접으로 알아야 합니다. 작은 학생 수와 큰 학생 수의 합이 N-1이면 됩니다.
2. 작은 쪽에서 큰 쪽으로 향하는 그래프와 반대로 향하는 그래프를 따로 만듭니다.
3. 학생마다 두 그래프에서 BFS를 한 번씩 돌려 닿는 학생 수를 셉니다. 자기 자신은 세지 않습니다.
4. 두 수의 합이 N-1인 학생이 순서를 아는 학생입니다. 그 수를 세어 출력합니다.

## 놓치기 쉬운 점

- BFS마다 방문 배열을 새로 만들고 시작점을 큐에 넣으면서 방문 표시를 합니다. 방문 표시를 빼면 같은 학생을 여러 번 셉니다.
- 인접 리스트가 비어 있으면 반복문이 0번 돌 뿐이라 따로 분기할 필요가 없습니다.
- 간선 방향을 헷갈리지 않습니다. 입력 `a b`는 a가 b보다 작다는 뜻입니다.
- 간선이 적은 그래프에서는 BFS가 유리하고 모든 쌍의 관계를 한 번에 정리할 때는 플로이드–워셜 풀이가 간결합니다.

## 복잡도와 검증

학생마다 BFS를 두 번 하므로 시간 O(N x (N + M)), 공간 O(N + M)입니다.

무작위 그래프 40개를 가능한 모든 줄 세우기에서 위치가 하나로 정해지는 학생 수와 비교해 확인했습니다. 관계를 늦게 발견하는 사례도 넣어 확인했습니다.
