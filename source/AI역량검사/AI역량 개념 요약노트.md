## Part 1. AI와 기계학습

근거 강의: 1-1 AI 기계학습 기초와 1-2 AI 기계학습 방법론. 1-2는 선형회귀에서 시작해 분류와 얕은 신경망을 거쳐 경사하강법과 역전파, MLP 실습으로 이어진다.

### 1. AI와 ML과 DL의 관계

| 구분 | 뜻 | 예 |
|---|---|---|
| AI | 인지와 추론으로 목표를 이루도록 행동하는 시스템 전체 | 규칙 기반 시스템, 탐색 알고리즘, 기계학습 모델 |
| ML | 데이터에서 규칙을 학습하는 AI 방법 | 선형회귀, 결정트리, 신경망 |
| DL | 신경망을 깊게 쌓아 학습하는 ML 방법 | CNN, RNN, Transformer |

- 포함관계는 AI ⊃ ML ⊃ DL이다. 규칙 기반 시스템은 AI이지만 ML은 아니다.
- 기계학습은 데이터, 모델, 학습, 평가를 반복하며 개선하는 순환이다.

### 2. 데이터와 학습의 구성

| 용어 | 뜻 |
|---|---|
| Feature(특성) | 예측에 쓰는 입력 정보 |
| Label(정답) | 모델이 맞혀야 하는 값 |
| 가설공간 | 학습이 고를 수 있는 후보 함수의 집합 |
| 손실 함수 | 후보 함수가 얼마나 틀리는지 재는 기준 |
| 학습 | 손실이 가장 작은 함수를 가설공간에서 찾는 과정 |

- 데이터는 $y = f(X) + \epsilon$으로 본다. $f$는 참 관계이고 $\epsilon$은 측정 오차처럼 줄일 수 없는 오차다.
- $f$를 학습하는 목적은 두 가지다. 새 입력의 값을 맞히는 예측과 입력이 출력에 주는 영향을 이해하는 추론이다.
- 지도학습은 Label이 있고 비지도학습은 Label 없이 구조를 찾는다.

### 3. 회귀와 분류

| 구분 | 출력 | 대표 손실 | 대표 평가 |
|---|---|---|---|
| 회귀 | 연속값(가격, 매출) | MSE | MSE, RMSE, $R^2$ |
| 분류 | 범주(스팸 여부, 품종) | 교차 엔트로피 | 정확도, 정밀도, 재현율, F1 |

- 손실은 학습 중에 줄이는 값이고 평가 지표는 학습이 끝난 뒤 성능을 보고하는 값이다. 둘이 같을 필요는 없다.

### 4. 평가 지표

회귀 지표:

- $\mathrm{MSE} = \frac{1}{n}\sum_i (y_i - \hat{y}_i)^2$이고 $\mathrm{RMSE}$는 그 제곱근이다. 큰 오차에 더 큰 벌점을 준다.
- $R^2 = 1 - \frac{\mathrm{RSS}}{\mathrm{TSS}}$는 평균으로만 예측할 때보다 얼마나 잘 설명하는지를 나타낸다. 평균보다 못하면 음수가 된다.

분류 지표 (양성 기준):

| 지표 | 식 | 뜻 |
|---|---|---|
| 정확도 | $\frac{TP+TN}{\text{전체}}$ | 전체 중 맞힌 비율 |
| 정밀도 | $\frac{TP}{TP+FP}$ | 양성이라 판정한 것 중 진짜 양성 |
| 재현율(TPR) | $\frac{TP}{TP+FN}$ | 진짜 양성 중 찾아낸 비율 |
| FPR | $\frac{FP}{FP+TN}$ | 진짜 음성을 양성으로 잘못 판정한 비율 |
| F1 | $\frac{2PR}{P+R}$ | 정밀도와 재현율의 조화평균 |

- 혼동행렬은 scikit-learn에서 행이 실제, 열이 예측이다. `cm[2, 0]`은 실제 2를 0으로 예측한 개수다.
- 불균형 데이터에서는 정확도가 높아도 소수 클래스를 놓칠 수 있다. 놓치면 안 되는 문제는 재현율을, 오탐 비용이 큰 문제는 정밀도를 본다.
- ROC 곡선은 임계값을 바꾸며 FPR(가로)과 TPR(세로)을 그린 곡선이다. AUC는 곡선 아래 면적이며 1에 가까울수록 좋고 0.5는 무작위 수준이다.

### 5. 과적합과 일반화

| 상태 | 학습 오차 | 검증 오차 | 대응 |
|---|---|---|---|
| 과소적합 | 높음 | 높음 | 더 표현력 있는 모델, 더 오래 학습 |
| 적절 | 낮음 | 낮음 | 유지 |
| 과적합 | 매우 낮음 | 높음 | 데이터 추가, 정규화, 조기 종료 |

- 데이터는 학습용, 검증용(모델과 하이퍼파라미터 선택), 테스트용(최종 보고)으로 나눈다. 테스트 자료로 모델을 고르면 성능을 과대평가한다.
- K-겹 교차검증은 겹치지 않는 K개 폴드를 돌아가며 검증하고 평균을 낸다. K가 n이면 LOOCV다.
- 층화 분할(`stratify`)은 학습용과 검증용의 클래스 비율을 원본과 비슷하게 맞춘다.
- 운영 데이터의 분포가 학습 때와 달라지면 과적합이 아니어도 성능이 떨어진다(분포 변화).

### 6. 선형회귀

- 단순선형회귀: $Y = \beta_0 + \beta_1 X + \epsilon$. 다중선형회귀: $Y = \beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p + \epsilon$.
- 최소제곱법은 잔차 제곱합 $\mathrm{RSS} = \sum_i (y_i - \hat{y}_i)^2$을 최소화하는 계수를 고른다.
- 단순회귀의 해: $\hat{\beta}_1 = \frac{\sum_i (x_i - \bar{x})(y_i - \bar{y})}{\sum_i (x_i - \bar{x})^2}$, $\hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x}$.
- 다중회귀의 정규방정식 해: $\hat{\beta} = (X^\top X)^{-1} X^\top y$.
- 다중회귀의 $\beta_j$는 다른 변수를 고정했을 때 $X_j$가 1 늘면 $Y$의 평균이 얼마나 변하는지를 뜻한다.
- 계수의 유의성은 t 통계량과 p-value로 본다. p-value가 작으면(보통 0.05 미만) 계수가 0이라는 가설을 기각한다.
- 다중공선성: 입력 변수끼리 상관이 크면 계수 추정이 불안정해지고 해석이 어려워진다.
- 상관관계는 인과관계가 아니다. 회귀계수가 유의해도 원인이라고 단정할 수 없다.

### 7. 로지스틱 회귀

- 선형식 $z = \beta_0 + \beta_1 x$에 시그모이드 $\sigma(z) = \frac{1}{1 + e^{-z}}$를 씌워 0과 1 사이의 확률을 낸다.
- 로그 오즈 $\log\frac{p}{1-p}$가 $x$에 대해 선형이다. 계수가 1 늘면 확률이 아니라 로그 오즈가 그만큼 는다.
- 계수는 최대우도추정(MLE)으로 구하고, 이는 이진 교차 엔트로피를 최소화하는 것과 같다.
- 확률이 임계값(기본 0.5) 이상이면 양성으로 판정한다. 임계값을 낮추면 재현율이 오르고 정밀도는 대개 내려간다.
- 분류에 선형회귀를 그대로 쓰면 예측이 0과 1 밖으로 나가고, 범주를 1, 2, 3으로 코딩하면 없는 순서가 생긴다.

### 8. 신경망과 표현력

- 선형층만 여러 겹 쌓으면 전체가 하나의 선형 함수다. 비선형 활성화(ReLU 등)가 있어야 곡선 경계를 표현한다.
- 얕은 신경망(은닉층 1개)도 은닉 유닛이 충분하면 연속함수를 원하는 정도로 근사할 수 있다(보편 근사 정리).
- 같은 파라미터 수라면 깊은 신경망이 더 많은 선형 구역을 만들어 표현력이 높다.

### 9. 경사하강법과 SGD

- 갱신식: $\phi_{t+1} = \phi_t - \alpha \frac{\partial L}{\partial \phi}$. $\alpha$는 학습률이다.
- 볼록(convex) 손실은 지역 최솟값이 곧 전역 최솟값이다. 비볼록 손실에는 여러 지역 최솟값과 안장점이 있다.
- 전체 데이터로 기울기를 구하는 GD는 정확하지만 한 번의 갱신이 비싸다.
- SGD(미니배치)는 일부 샘플로 기울기를 근사한다. 계산이 싸고, 기울기에 섞인 잡음이 지역 최솟값과 안장점에서 벗어나는 데 도움이 된다. 다만 항상 더 빨리 수렴하는 것은 아니다.

| 용어 | 뜻 |
|---|---|
| 배치 | 한 번의 갱신에 쓰는 샘플 묶음 |
| 이터레이션 | 배치 하나로 한 번 갱신 |
| 에폭 | 학습 데이터 전체를 한 번 사용 |

### 10. 역전파와 학습 루프

- 순전파로 출력과 손실을 구하고, 역전파는 연쇄법칙으로 출력 쪽부터 입력 쪽으로 각 파라미터의 기울기를 구한다.
- 연쇄법칙: $\frac{\partial y}{\partial \Omega} = \frac{\partial y}{\partial f} \cdot \frac{\partial f}{\partial \Omega}$. 순전파에서 계산한 중간값을 저장해 두고 역전파에서 재사용한다.
- 학습 중에 바뀌는 값은 가중치와 편향(파라미터)이다. 학습률과 배치 크기는 사람이 정하는 하이퍼파라미터다.

```python
class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(4, 16)
        self.fc2 = nn.Linear(16, 3)

    def forward(self, x):
        h = torch.relu(self.fc1(x))
        return self.fc2(h)
```

- `model(x)`처럼 호출하면 `__call__`이 `forward`를 실행한다. `forward`를 직접 부르지 않는다.
- 학습 루프 순서: 기울기 초기화 → 예측 → 손실 → 역전파 → 가중치 갱신. 순서는 Part 6에 코드로 있다.
- 조기 종료: 검증 손실이 일정 에폭 동안 나아지지 않으면 학습을 멈춘다.

### 11. 비지도 학습과 차원 축소

- K-means는 K를 정해 두고 각 점을 가장 가까운 중심에 배정한다. 초기 중심에 따라 결과가 달라질 수 있어 여러 번 실행한다.
- 거리 기반 방법은 단위가 다른 특성을 표준화한 뒤 쓴다.
- PCA는 분산이 큰 방향(주성분)으로 데이터를 투영해 정보를 최대한 남기며 차원을 줄인다. 2차원이나 3차원으로 줄여 시각화에 쓴다.

### Part 1 자주 틀리는 포인트

- "규칙 기반 시스템은 ML의 한 종류"가 아니다. AI이지만 데이터로 학습하지 않는다.
- "정확도 99%면 좋은 모델"이 아닐 수 있다. 양성이 1%인 자료에서는 전부 음성이라고 해도 99%다.
- "R²는 항상 0~1"이 아니다. 평균보다 못한 모델은 음수다.
- "SGD는 항상 GD보다 빨리 수렴"하지 않는다. 한 번의 갱신이 싸고 잡음이 있을 뿐이다.
- "활성화 없이 층을 쌓아도 비선형"이 되지 않는다.

## Part 2. 자연어 처리

근거 강의: 2-1 자연어처리 기본. 워드 임베딩에서 RNN과 LSTM을 거쳐 Transformer와 사전학습 언어 모델, In-Context Learning까지 다룬다. 3-1 2차시의 RNN과 어텐션도 여기서 함께 정리한다.

### 1. 원-핫 인코딩과 워드 임베딩

| 구분 | 원-핫 | 워드 임베딩 |
|---|---|---|
| 차원 | 어휘 수(수만 이상) | 보통 수십~수백 |
| 형태 | 하나만 1인 희소 벡터 | 실수로 채운 밀집 벡터 |
| 의미 유사도 | 모든 단어가 직교해 내적이 0 | 비슷한 단어가 가까이 위치 |

- 원-핫의 한계는 차원의 저주(희소하고 큼)와 의미 정보 부족이다. "핸드폰"과 "스마트폰"을 전혀 다른 벡터로 본다.
- 분포 가설: 단어의 의미는 함께 나타나는 주변 단어가 정한다.

### 2. Word2Vec

| 방식 | 예측 방향 | 장점 | 한계 |
|---|---|---|---|
| Skip-gram | 중심 단어 → 주변 단어 | 적은 데이터에서도 잘 동작, 희귀 단어 표현에 강함 | 학습이 느림 |
| CBOW | 주변 단어 → 중심 단어 | 학습이 빠름, 자주 나오는 단어에 강함 | 희귀 단어 표현이 약함 |

- 윈도우 크기는 중심 단어 앞뒤로 몇 개를 주변 단어로 볼지 정한다.

### 3. 순차 데이터와 RNN

- 순차 데이터의 특징: 순서가 의미를 바꾸고, 멀리 떨어진 정보가 영향을 주며(장기 의존성), 길이가 가변적이다.
- RNN의 은닉 상태: $h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t)$, 출력: $y_t = W_{hy} h_t$.
- 모든 시점이 같은 가중치를 공유한다. 그래서 길이가 다른 입력을 같은 모델로 처리한다.

| 입출력 구조 | 예 |
|---|---|
| One-to-Many | 이미지 한 장 → 설명 문장 |
| Many-to-One | 문장 → 감성 분류 |
| Many-to-Many | 문장 → 번역 문장, 프레임별 라벨 |

### 4. 기울기 소실과 폭발

- 시간축 역전파(BPTT)에서 같은 $W$가 시점 수만큼 곱해진다. $W$의 크기(특잇값)가 1보다 크면 기울기가 폭발하고 1보다 작으면 소실된다.
- 기울기 클리핑은 폭발은 막지만 소실은 해결하지 못한다. 소실은 구조를 바꿔(LSTM) 해결한다.
- RNN은 시점을 순서대로 계산해야 하므로 병렬화가 어렵고 대규모 학습이 느리다.

### 5. LSTM

| 구성 | 역할 |
|---|---|
| 셀 상태 $c_t$ | 장기 정보를 나르는 경로 |
| 망각 게이트 $f$ | 이전 셀 정보를 얼마나 지울지 |
| 입력 게이트 $i$ | 새 정보 $g$를 얼마나 저장할지 |
| 출력 게이트 $o$ | 셀 정보를 은닉 상태로 얼마나 내보낼지 |

- $c_t = f \odot c_{t-1} + i \odot g$, $h_t = o \odot \tanh(c_t)$.
- 셀 상태가 덧셈으로 이어져 기울기가 오래 전달된다. 다만 아주 긴 시퀀스에서는 정보가 점점 희석된다.

### 6. Seq2Seq와 어텐션

- Seq2Seq는 인코더가 입력 전체를 고정 길이 벡터 하나로 압축하고 디코더가 출력을 생성한다. 긴 입력에서는 이 벡터가 병목이 되어 정보를 잃는다.
- 어텐션은 디코더가 매 시점 인코더의 모든 은닉 상태를 보고 필요한 부분에 가중치를 주어 합친다. 가중치를 보면 어디를 참고했는지 알 수 있다.

### 7. 셀프 어텐션과 Transformer

- 쿼리, 키, 값: $Q = XW_Q$, $K = XW_K$, $V = XW_V$.
- $\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$. $\sqrt{d_k}$로 나누어 내적이 커져 softmax가 한쪽으로 쏠리는 것을 막는다.
- 셀프 어텐션은 한 입력 안의 요소끼리, 교차 어텐션은 서로 다른 입력(예: 텍스트 쿼리와 이미지 키)끼리 관계를 본다.

| 구성요소 | 역할 |
|---|---|
| 멀티헤드 어텐션 | 여러 헤드가 서로 다른 관계를 동시에 본다 |
| 위치 인코딩 | 어텐션은 순서를 모르므로 위치 정보를 더한다 |
| 피드포워드층 | 토큰마다 비선형 변환을 한다 |
| 잔차 연결과 층 정규화 | 깊은 망의 학습을 안정시킨다 |
| 마스크드 셀프 어텐션 | 디코더가 미래 토큰을 보지 못하게 막는다 |

- 모든 토큰을 한 번에 처리해 병렬 학습이 쉽고 먼 거리 관계를 바로 잡는다. 대신 시퀀스 길이의 제곱에 비례하는 계산이 든다.

### 8. 사전학습 언어 모델의 세 계열

| 계열 | 대표 | 사전학습 방식 | 강점 |
|---|---|---|---|
| 인코더 | BERT | 가린 단어 맞히기(MLM), 양방향 문맥 | 분류, 개체명 인식, 질의응답 |
| 인코더-디코더 | T5 | 모든 과제를 텍스트 → 텍스트로 | 번역, 요약 |
| 디코더 | GPT | 다음 토큰 예측, 왼쪽 문맥만 | 생성. 현재 LLM의 주류 |

### 9. In-Context Learning과 Chain-of-Thought

- In-Context Learning: 가중치를 바꾸지 않고 프롬프트의 설명과 예시만으로 과제를 수행한다. 예시 수에 따라 Zero-shot, One-shot, Few-shot이다.
- Few-shot CoT는 풀이 과정을 담은 예시를 보여 준다. Zero-shot CoT는 "단계별로 생각해 보자" 같은 문장만 덧붙인다.
- Self-consistency는 여러 추론 경로를 샘플링해 가장 많이 나온 답을 고른다.
- 예시를 늘리면 컨텍스트 길이와 비용이 늘어난다. 반복 업무라면 파인튜닝과 비교한다.

### 10. 텍스트 모델의 텐서 모양

```python
emb = nn.Embedding(1000, 32)
lstm = nn.LSTM(
    32, 64, batch_first=True)
x = torch.randint(0, 1000, (4, 10))
out, (h, c) = lstm(emb(x))
# emb(x): (4, 10, 32)
# out: (4, 10, 64)
# h, c: (1, 4, 64)
```

- `nn.Embedding`의 입력은 정수(`long`) 토큰 번호다.
- `batch_first=True`이면 입력과 `out`이 (배치, 길이, 특성) 순서다. `h`와 `c`는 이 옵션과 상관없이 (층 수 × 방향 수, 배치, 은닉 크기)다.
- 문장 분류에는 마지막 은닉 상태 `h[-1]`이나 `out`의 평균을 쓴다.

### 1. FCN과 CNN

- 완전연결망(FCN)은 이미지를 1차원으로 펼쳐 넣는다. 공간 구조가 사라지고 파라미터가 입력 크기에 비례해 매우 많아진다.
- CNN은 작은 필터를 이미지 위에서 움직이며 같은 가중치로 계산한다. 지역성과 가중치 공유 덕분에 파라미터가 적고 위치가 조금 바뀌어도 같은 특징을 잡는다.
- 기본 흐름: 합성곱 → 활성화 → 풀링을 반복하고 마지막에 완전연결층으로 분류한다.

### 2. 합성곱 계산

입력 $C_{in} \times H \times W$, 필터 $K \times K$, 필터 수 $C_{out}$, 패딩 $P$, 스트라이드 $S$일 때:

| 항목 | 식 |
|---|---|
| 출력 크기 | $H' = \lfloor \frac{H - K + 2P}{S} \rfloor + 1$ |
| 출력 채널 | $C_{out}$ (필터 개수) |
| 필터 하나의 깊이 | $C_{in}$ (입력 채널 수) |
| 파라미터 수 | $K^2 C_{in} C_{out} + C_{out}$ (편향 포함) |
| 곱셈 연산 수 | $H' W' \times K^2 C_{in} C_{out}$ |

AlexNet 첫 층 예시 (입력 $3 \times 227 \times 227$, $11 \times 11$ 필터 96개, 스트라이드 4, 패딩 0):

- 출력 크기: $\frac{227 - 11}{4} + 1 = 55$ → $96 \times 55 \times 55$.
- 파라미터: $96 \times 3 \times 11 \times 11 + 96 = 34{,}944$.
- 출력 메모리(FP32): $96 \times 55 \times 55 \times 4$ 바이트 $= 1{,}161{,}600$ 바이트(약 1,134KB).
- 곱셈 연산: $55 \times 55 \times (3 \times 11 \times 11 \times 96) \approx 105.4$M.
- 메모리는 앞쪽 합성곱층에, 파라미터는 뒤쪽 완전연결층에, 연산은 합성곱층에 몰린다.

```python
conv = nn.Conv2d(
    1, 8, kernel_size=3, padding=1)
x = torch.zeros(4, 1, 8, 8)
print(conv(x).shape)
# torch.Size([4, 8, 8, 8])
```

- PyTorch 이미지 텐서는 (배치, 채널, 높이, 너비) 순서다. 위 층의 파라미터는 $8 \times 1 \times 3 \times 3 + 8 = 80$개다.

### 3. 풀링과 수용영역, 1×1 합성곱

- 맥스 풀링은 구역의 최댓값만 남겨 크기를 줄인다. 학습할 파라미터가 없고 작은 위치 변화에 강해진다.
- 스트라이드가 있는 합성곱도 크기를 줄이지만 학습 파라미터가 있다.
- 수용영역은 출력 한 칸이 보는 입력 범위다. 층이 깊어질수록 넓어진다.
- 1×1 합성곱은 공간 크기는 그대로 두고 채널 수를 줄이거나 늘린다. 연산을 줄이는 데 쓴다.

### 4. 대표 CNN 모델

| 모델 | 핵심 아이디어 |
|---|---|
| AlexNet (2012) | 합성곱 5층과 완전연결 3층. ReLU와 드롭아웃을 쓰고 GPU 두 대로 학습 |
| VGGNet (2014) | 3×3 합성곱만 반복하는 단순한 설계. 깊이 16~19층, 파라미터가 많음(VGG-16 약 138M) |
| GoogLeNet (2014) | 여러 크기의 필터를 병렬로 쓰는 Inception 블록, 1×1 합성곱으로 연산 절감 |
| ResNet (2015) | 잔차 연결 $F(x) + x$로 100층 이상을 안정적으로 학습 |
| MobileNet (2017) | 깊이별 합성곱과 1×1 화소별 합성곱으로 나눠 모바일 환경에서 동작 |

- VGG: 3×3 두 층은 5×5 한 층과 수용영역이 같다. 파라미터는 $18C^2$ 대 $25C^2$로 적고 비선형 활성화가 하나 더 들어간다.
- ResNet이 해결한 문제는 과적합이 아니라 성능 저하(degradation)다. 56층 망이 20층 망보다 학습 오차까지 높았다.
- 잔차 블록은 최적이 항등 함수에 가까울 때 $F(x)$를 0으로만 만들면 되므로 깊어져도 최소한 얕은 망의 성능을 유지하기 쉽다.
- ResNet-50 이상은 1×1 → 3×3 → 1×1의 병목 블록으로 연산을 줄인다.
- MobileNet 연산 절감: 일반 합성곱 $9C^2HW$, 분리 합성곱 $9CHW + C^2HW$. 비율 $\frac{9C}{9 + C}$은 $C$가 크면 약 9배다.

### 5. ViT(Vision Transformer)

- 이미지를 고정 크기 패치(예: 16×16)로 자르고 각 패치를 선형 변환해 토큰으로 만든다. 224×224 이미지면 $14 \times 14 = 196$개 패치다.
- 분류용 토큰과 위치 인코딩을 더해 Transformer 인코더에 넣고, 분류용 토큰의 출력을 MLP 헤드로 분류한다.
- 인코더 블록: 층 정규화 → 멀티헤드 어텐션 → 잔차 연결 → 층 정규화 → MLP → 잔차 연결.

| 위치 인코딩 | 장점 | 단점 |
|---|---|---|
| 학습 가능한 인코딩 | 데이터에 맞게 최적화 | 해상도가 바뀌면 다시 학습 필요 |
| 사인파 인코딩 | 해상도가 바뀌어도 그대로 적용 | 고정형이라 과제에 특화되지 않음 |
| 상대 위치 인코딩 | 해상도 변화에 강함 | 절대 위치(위아래, 좌우)를 반영하기 어려움 |

| 비교 | CNN | ViT |
|---|---|---|
| 보는 범위 | 지역에서 시작해 점점 넓어짐 | 첫 층부터 이미지 전체 |
| 귀납 편향 | 지역성과 가중치 공유가 내장 | 거의 없음 |
| 데이터가 적을 때 | 유리 | 불리 |
| 대규모 사전학습 후 | 좋음 | CNN을 앞섬(JFT-300M 같은 대규모 자료) |

### 6. ViT 학습과 발전

- ViT는 파라미터가 많아 정규화와 데이터 증강이 매우 중요하다.
- DeiT: CNN 선생님 모델의 예측을 따라 하도록 증류 토큰을 추가해 학습한다. 대규모 외부 데이터 없이 ImageNet만으로 성능을 크게 올렸다.
- Swin Transformer: 창(window) 안에서만 어텐션을 계산하고 다음 층에서 창을 옮겨 창끼리 정보를 섞는다. 계층적 특징을 만들어 검출과 분할에 강하다.
- ViT의 장점은 전역 문맥과 멀티모달 확장성이고 단점은 대규모 학습 자원과 소규모 데이터에서의 약세다.

### 7. 활성화 함수

| 함수 | 식 | 장점 | 문제 |
|---|---|---|---|
| Sigmoid | $\frac{1}{1 + e^{-x}}$ | 0~1 확률처럼 해석 | 포화 구간에서 기울기 소실, 출력이 항상 양수, 지수 계산 |
| Tanh | $\frac{e^x - e^{-x}}{e^x + e^{-x}}$ | 0 중심(−1~1) | 포화로 인한 기울기 소실 |
| ReLU | $\max(0, x)$ | 양수 구간 포화 없음, 계산이 빠름 | 입력이 계속 음수면 죽은 뉴런 |
| Leaky ReLU | $\max(0.01x, x)$ | 음수 구간에도 작은 기울기 | 기울기 값이 하이퍼파라미터, 항상 ReLU보다 낫지는 않음 |
| ELU | $x$ 또는 $\alpha(e^x - 1)$ | 평균 출력이 0에 가까움 | 지수 계산, $\alpha$ 선택 |

- 결론: 은닉층은 ReLU로 시작하고 개선이 필요하면 Leaky ReLU나 ELU를 시도한다. Sigmoid와 Tanh는 은닉층 기본값으로 쓰지 않는다.

### 8. 데이터 전처리

- 학습과 검증과 테스트에 같은 전처리를 적용한다. 해상도, 색 채널(RGB와 BGR), 정규화 값이 다르면 성능이 크게 떨어진다.
- 일반적인 정규화는 평균 0, 표준편차 1이다. 평균과 표준편차는 학습 자료로만 계산하고 검증과 테스트에도 그 값을 쓴다.
- 흑백 이미지를 3채널 모델에 넣을 때는 채널을 복제해 3채널로 맞춘다.
- 모델별 예: AlexNet은 평균 이미지 빼기, VGG는 채널별 평균 빼기, ResNet은 채널별 평균 빼기와 표준편차로 나누기.

### 9. 가중치 초기화

| 방법 | 내용 | 결과 |
|---|---|---|
| 0으로 초기화 | 모든 가중치와 편향이 0 | 모든 뉴런이 같은 값과 기울기를 가져 학습이 안 됨 |
| 작은 무작위 값 | 예: $0.01 \times \mathcal{N}(0, 1)$ | 얕은 망은 되지만 깊은 망에서 활성값이 0으로 줄어 기울기 소실 |
| Xavier | 표준편차 $\frac{1}{\sqrt{D_{in}}}$ | 입출력 분산을 맞춤. tanh에 적합 |
| He | 표준편차 $\sqrt{\frac{2}{D_{in}}}$ | ReLU가 절반을 0으로 만드는 것을 보정 |

- ResNet은 He 초기화를 쓰고 잔차 경로의 마지막 합성곱을 0으로 초기화하기도 한다. 그러면 처음에는 블록이 항등 함수처럼 동작해 학습이 안정적이다.

### 10. 정규화: 가중치 감쇠와 드롭아웃

| 기법 | 벌점 | 효과 |
|---|---|---|
| L2(Ridge, 가중치 감쇠) | $\sum w^2$ | 모든 가중치를 고르게 작게 |
| L1(Lasso) | $\sum \lvert w \rvert$ | 중요하지 않은 가중치를 정확히 0으로(특성 선택) |
| Elastic Net | L1 + L2 | 둘의 장점을 함께 |

- 벌점은 원래 손실에 더해 함께 줄인다. 벌점만 줄이면 모든 가중치가 0이 되어 의미가 없다.
- 드롭아웃은 학습 중 뉴런을 확률 $p$로 끈다. 매번 다른 작은 망을 학습하는 앙상블 효과로 과적합을 줄인다. 테스트에서는 모든 뉴런을 쓴다.
- 역 드롭아웃: 학습 때 살아남은 출력에 $\frac{1}{1-p}$를 곱해 두면 테스트 때 따로 보정하지 않아도 된다. PyTorch의 `nn.Dropout(p)`가 이 방식이며 `p`는 끌 확률이다.
- `model.eval()`을 부르지 않으면 평가 때도 드롭아웃이 켜져 같은 입력의 출력이 매번 달라진다.

### 11. 학습률 조정과 조기 종료

- 학습률이 너무 크면 손실이 발산하거나 요동치고 너무 작으면 매우 느리게 줄어든다.

| 스케줄 | 식 또는 방식 |
|---|---|
| 계단식 | 정해진 에폭마다 $\gamma$배(예: 0.1배)로 줄임 |
| 코사인 | $\eta_t = \frac{\eta_0}{2}\left(1 + \cos\frac{\pi t}{T}\right)$ |
| 선형 | $\eta_t = \eta_0 \left(1 - \frac{t}{T}\right)$ |
| 역제곱근 | $\eta_t = \frac{\eta_0}{\sqrt{t}}$ |
| 고정 | $\eta_t = \eta_0$ |

- 계단식은 변경 시점을 정해야 하고 손실 곡선이 계단처럼 급히 바뀐다. 코사인은 처음에는 크게 나중에는 미세하게 조정한다.
- 조기 종료는 검증 지표가 나빠지기 시작하는 시점에 멈추는 과적합 방지 방법이다.

### 12. 하이퍼파라미터와 학습 점검 순서

- 파라미터는 학습으로 얻는 값(가중치, 편향)이고 하이퍼파라미터는 학습 전에 정해 학습 중 고정되는 값이다.

| 분류 | 예 |
|---|---|
| 학습 | 학습률과 스케줄, 배치 크기, 에폭 수 |
| 최적화 | 최적화 도구(SGD, Adam, AdamW), 모멘텀, 가중치 감쇠 |
| 모델 구조 | 깊이, 채널 수, 드롭아웃 비율, 정규화층 종류 |

- 그리드 탐색은 정해 둔 조합을 모두 시도한다. 랜덤 탐색은 무작위 조합을 시도하며, 중요한 하이퍼파라미터가 일부일 때 같은 횟수로 더 다양한 값을 본다.

학습 점검 순서:

1. 초기 손실 확인: 클래스가 $C$개인 분류에서 학습 전 교차 엔트로피는 약 $\ln C$다. 10클래스면 약 2.3이다. 크게 다르면 데이터나 손실 구현을 의심한다.
2. 작은 샘플로 과적합시키기: 정규화 없이 학습 정확도 100%가 나오는지 본다. 안 되면 학습률, 초기화, 구조, 코드 버그를 의심한다.
3. 손실이 실제로 줄어드는 학습률 찾기: 1e-1부터 1e-4까지 로그 간격으로 짧게(약 100 이터레이션) 시도한다.
4. 후보 조합을 1~5에폭만 돌려 비교한다.
5. 좋은 조합을 10~20에폭 학습한다.
6. 손실과 정확도 곡선을 해석한다.

| 곡선 모양 | 해석 |
|---|---|
| 초반 손실이 한동안 평평하다가 떨어짐 | 초기화 문제 |
| 손실이 줄다가 정체 | 학습률 감소를 시도 |
| 학습률을 줄인 직후부터 학습이 멈춤 | 정체가 오기 전에 너무 일찍 줄임 |
| 학습 정확도는 오르는데 검증 정확도와 격차가 커짐 | 과적합. 정규화나 데이터 추가 |
| 학습과 검증의 격차가 거의 없고 정확도가 더 오르지 않음 | 모델이 약함. 더 큰 모델로 더 오래 학습 |

### 13. 전이 학습

| 방법 | 학습 범위 | 장점 | 단점 |
|---|---|---|---|
| 선형 프로빙 | 백본 고정, 마지막 분류층만 | 빠르고 자원이 적게 들며 과적합 위험이 낮음 | 도메인이 다르면 성능 한계 |
| 파인 튜닝 | 전체 또는 일부 층 | 높은 성능 | 계산 자원이 많이 들고 데이터가 적으면 과적합 |

```python
for p in model.parameters():
    p.requires_grad = False
model.fc = nn.Linear(512, 10)
n = sum(p.numel()
        for p in model.parameters()
        if p.requires_grad)
```

- 새로 만든 층은 `requires_grad`가 기본값 `True`라서 위 코드에서 학습되는 파라미터는 `fc`의 $512 \times 10 + 10 = 5{,}130$개뿐이다.
- 데이터 증강: 이미지는 회전과 뒤집기와 자르기, 텍스트는 동의어 치환과 역번역, 음성은 시간 늘이기와 잡음 추가.

- ResNet은 과적합이 아니라 깊어질수록 학습 오차도 커지는 성능 저하를 해결했다.

## Part 4. LLM과 에이전트

근거 강의: 4-1.

| 차시 | 내용 |
|---|---|
| 1차시 | 사후학습: Instruction-tuning과 RLHF, DPO와 RLVR |
| 2차시 | 검색 증강 언어 모델과 정보 검색 |
| 3차시 | LLM 에이전트와 도구 사용, MCP |
| 4차시 | AI Agents와 LangChain, 실습 RAG |

### 1. 사전학습과 사후학습

| 단계 | 데이터 | 목표 |
|---|---|---|
| 사전학습 | 방대한 비라벨 텍스트 | 다음 토큰 예측으로 언어와 지식 학습(자기지도) |
| 사후학습 | 지시와 응답, 사람의 선호 | 사람의 의도에 맞게 대화하고 안전하게 답하도록 조정 |

- 사전학습만 한 모델은 질문에 답하지 않고 비슷한 문장을 이어 쓰기도 한다.
- 사후학습 방법: Instruction-tuning, RLHF, DPO, RLVR.

### 2. Instruction-tuning

- 여러 과제의 (지시문, 입력, 출력) 쌍을 모아 지도학습으로 파인튜닝한다. 학습하지 않은 새 과제로도 일반화된다.
- 데이터 예: Super-NaturalInstructions(1,600개 이상 과제), Alpaca(LLaMA 7B를 다른 모델로 만든 5만 2천 개 지시 데이터로 튜닝), LIMA(고품질 1,000개로도 충분할 수 있음).
- 평가 예: MMLU(57개 분야 객관식), 한국어판 K-MMLU.
- 한계: 정답 데이터 수집이 비싸다. 창작처럼 정답이 하나가 아닌 과제가 있다. 토큰 단위 손실은 사소한 오류와 치명적 오류를 같은 무게로 본다. 사람이 쓴 정답이 최선이 아닐 수 있다.

### 3. RLHF

1. 시범 데이터로 지도 파인튜닝(SFT)을 한다.
2. 같은 질문에 대한 여러 응답을 사람이 비교해 순위를 매기고, 이 비교 데이터로 보상 모델을 학습한다.
3. 보상 모델의 점수가 높아지도록 강화학습(PPO)으로 언어 모델을 최적화한다. SFT 모델에서 너무 멀어지지 않도록 제약을 둔다.

- 절대 점수 대신 비교를 쓰는 이유: 사람마다 점수 기준이 달라 일관성이 떨어지기 때문이다.
- 보상 모델 학습 손실(쌍 비교): $-\log \sigma\big(r(x, y_w) - r(x, y_l)\big)$. $y_w$는 선호된 응답, $y_l$은 덜 선호된 응답이다.
- InstructGPT(2022)에서 정리됐고 ChatGPT가 이 방식으로 상용화됐다.

### 4. RLHF의 한계와 DPO, RLVR

- 보상 해킹: 실제 목표 대신 보상 점수만 올리는 편법을 학습한다.
- 환각: 도움이 되어 보이는 답을 만들도록 학습되면서 사실이 아닌 내용을 자신 있게 말한다.
- 보상 모델 과최적화: 보상 모델 점수는 계속 오르는데 실제 사람의 선호도는 어느 시점부터 떨어진다.
- 사람의 선호는 일관되지 않다.

| 방법 | 특징 |
|---|---|
| DPO | 별도 보상 모델과 강화학습 없이 선호 데이터로 언어 모델을 직접 최적화. 단순하고 안정적 |
| RLVR | 수학과 코드처럼 정답을 자동으로 확인할 수 있는 문제에서 맞으면 1, 틀리면 0을 보상으로 줌. 사람 피드백이 필요 없음 |

### 5. 검색 증강 언어 모델(RAG)

- 추론할 때 외부 데이터 저장소에서 관련 문서를 검색해 질문과 함께 언어 모델에 넣는다.

| 구성 | 뜻 |
|---|---|
| 데이터 저장소 | 가공하지 않은 대규모 텍스트. 라벨이나 정형 지식베이스가 아님 |
| 쿼리 | 검색에 쓰는 입력. 언어 모델의 입력과 같을 필요는 없음 |
| 인덱스 | 문서를 빠르게 찾도록 정리한 구조 |
| 검색(Retrieval) | 쿼리와 관련성이 높은 문서를 찾는 과정 |

필요한 이유:

1. 모든 지식을 파라미터에 담을 수 없다. 자주 나오지 않는 정보일수록 모델이 틀린다.
2. 지식이 금방 낡는다. 모델 편집은 어렵지만 저장소 갱신은 쉽다.
3. 근거 문서를 보여 줄 수 있어 답을 검증하기 쉽다.
4. 사내 정보를 모델 학습에 넣지 않고도 쓸 수 있다.

- 과제: 검색한 문서가 많아지면 컨텍스트 길이가 부족하다. 무관한 문서가 섞이면 오히려 환각이 늘 수 있다.

### 6. 정보 검색: Sparse와 Dense

TF-IDF 가중치: $w_{x,y} = tf_{x,y} \times \log\frac{N}{df_x}$

- $tf_{x,y}$: 문서 $y$에서 단어 $x$의 빈도. $df_x$: 단어 $x$가 나온 문서 수. $N$: 전체 문서 수.
- 거의 모든 문서에 나오는 단어("the", "is")는 $\log\frac{N}{df_x}$가 0에 가까워 가중치가 작다.

| 구분 | Sparse 검색 | Dense 검색 |
|---|---|---|
| 기반 | 단어 일치(TF-IDF, BM25) | 임베딩 벡터의 의미 유사도 |
| 장점 | 단순하고 빠름(역색인), 결과를 설명하기 쉬움 | 동의어와 다양한 표현을 잡음, 문맥을 반영 |
| 단점 | 의미 이해가 약함("bad guy"와 "villain"을 못 잇는다) | 계산 비용이 큼, 왜 검색됐는지 설명하기 어려움, 학습 데이터에 의존 |

- 정확한 코드나 고유명사 검색은 Sparse가 강하다. 두 방식을 섞는 하이브리드 검색도 쓴다.

### 7. Bi-encoder와 Cross-encoder

| 구분 | Bi-encoder | Cross-encoder |
|---|---|---|
| 입력 | 쿼리와 문서를 따로 인코딩 | "쿼리 [SEP] 문서"를 한 번에 인코딩 |
| 속도 | 빠름. 문서 벡터를 미리 계산 | 느림. 쌍마다 계산 |
| 정확도 | 상대적으로 낮음 | 쿼리와 문서의 상호작용을 봐서 높음 |
| 쓰임 | 대규모 1차 검색 | 상위 후보의 재순위 |

- Bi-encoder는 대조 학습으로 관련 문서는 가깝게, 무관한 문서는 멀게 학습한다.

### 8. LLM 에이전트

- 에이전트: 센서로 환경을 인식하고 행동으로 환경에 영향을 주는 존재. LLM 에이전트는 LLM을 핵심으로 환경을 이해하고 행동한다.

| 구성요소 | 역할 |
|---|---|
| Controller | 사용자 요청을 이루는 실행 계획을 세움 |
| Tool Set | 서로 다른 기능을 가진 도구 모음 |
| Perceiver | 환경의 피드백을 요약해 Controller에 전달 |
| Environment | 도구가 실제로 동작하는 플랫폼 |

- 성공적인 에이전트에 필요한 것: 도구 사용, 추론과 계획, 환경 표현, 환경 이해, 상호작용과 의사소통.
- 판별 예: 웹을 탐색하는 LLM 시스템과 파일을 찾아 코드로 처리하는 시스템은 에이전트다. 한 번 검색하고 생성하는 RAG는 점진적 상호작용이 없어 에이전트로 보기 어렵다. 외부 환경과 상호작용하지 않는 추론 모델 단독은 에이전트가 아니다.

### 9. 도구 사용과 도구 학습

- 도구: LLM이 외부 프로그램을 쓰게 하는 함수 인터페이스. LLM은 함수 이름과 인자를 생성하고 실행은 외부에서 한다.
- 텍스트 생성 모드에서 도구 호출을 만들면 도구 실행 모드로 바뀌고, 실행 결과가 다시 텍스트로 들어간다.
- 도구 사용을 이끄는 방법: 추론 시 프롬프트로 지시하거나 도구 사용 자체를 학습시킨다.

| 연구 | 학습 방식 |
|---|---|
| WebGPT (2022) | 사람의 검색 행동 기록을 모방 학습(지도학습 후 강화학습) |
| Toolformer (2023) | 자기지도. ① API 호출 후보를 생성 ② 실제로 실행 ③ 다음 토큰 예측 손실을 줄이는 호출만 남겨 학습 데이터로 씀 |
| ToolLLM (2023) | 1만 6천 개 이상의 실제 API로 지시와 풀이 경로 데이터를 만들어 학습 |

### 10. MCP(Model Context Protocol)

- 등장 배경: 회사와 플랫폼마다 도구 호출 형식이 달라 같은 도구를 모델마다 다시 정의해야 했다. MCP는 LLM이 외부 도구와 데이터에 연결하는 방식을 표준화한 프로토콜이다(USB-C에 비유).

| 구성 | 역할 |
|---|---|
| MCP Host | 하나 이상의 MCP 클라이언트를 관리하는 AI 애플리케이션 |
| MCP Client | MCP 서버 하나와 1:1로 연결을 유지하며 컨텍스트를 가져옴 |
| MCP Server | 클라이언트에 도구(Tools)와 리소스(Resources)와 프롬프트(Prompts)를 제공하는 프로그램 |

| 계층 | 역할 |
|---|---|
| Data Layer(내부) | JSON-RPC 2.0 기반 메시지 형식. 연결 수명주기, 도구와 리소스와 프롬프트, 알림을 정의 |
| Transport Layer(외부) | 실제 통신 채널(stdio, HTTP). 연결 수립, 메시지 프레이밍, 인증 |

- 장점: 표준화, 새 도구를 쉽게 추가하는 확장성, 모델과 플랫폼 사이의 호환성, 한 번 만든 도구의 재사용, 호출 과정의 투명성.

```python
from fastmcp import FastMCP

mcp = FastMCP("calc")


@mcp.tool()
def add(a: int, b: int) -> int:
    """Add two numbers."""
    return a + b


if __name__ == "__main__":
    mcp.run()
```

- 타입 힌트와 docstring이 도구 설명(JSON 스키마)으로 바뀌어 클라이언트에 전달된다.

### 12. LangChain과 RAG 실습

- LangChain: LLM 애플리케이션을 빠르게 만드는 오픈소스 프레임워크. 여러 모델 제공사를 같은 인터페이스로 쓰고 구성요소를 재사용한다. 복잡한 흐름은 그래프 기반 LangGraph로 설계한다.

| 구성요소 | 역할 |
|---|---|
| Prompt Template | 프롬프트를 틀로 만들어 변수만 바꿔 씀 |
| Chain | 여러 단계를 연결한 작업 흐름 |
| Agent | 상황에 따라 도구를 골라 실행 |
| Memory | 대화 기록과 상태 유지 |
| Tool | 외부 API, DB, 계산기 등과 연결 |

RAG 파이프라인:

1. 문서 불러오기
2. 청킹: 긴 문서를 컨텍스트 창에 맞는 의미 단위 조각으로 나눈다.
3. 임베딩: 조각을 의미를 담은 숫자 벡터로 바꾼다.
4. 벡터 저장소: 벡터를 저장하고 유사도 검색을 제공한다(예: Chroma).
5. 리트리버: 질문과 의미가 가까운 조각을 찾는다(`vectorstore.as_retriever()`).
6. 검색 결과를 프롬프트에 넣어 LLM이 답을 생성한다.

- 에이전트에서는 리트리버를 도구로 바꿔(`create_retriever_tool`) 필요할 때만 검색하게 한다. 일반 함수는 `@tool` 데코레이터로 도구로 등록한다.
- 청크가 너무 작으면 문맥이 끊기고 너무 크면 무관한 내용이 섞여 검색 정확도가 떨어진다.

## Part 5. 리소스 최적화

근거 강의: 5-1 리소스 효율적 학습법. 앞부분은 컴퓨터의 수 체계(고정소수점과 부동소수점과 연산 복잡도)이고, 뒷부분은 모델 경량화(양자화와 가지치기와 지식 증류)와 LoRA를 포함한 효율적 파인튜닝이다.

### 1. 진법과 비트

- $1101_2 = 8 + 4 + 0 + 1 = 13$, $47 = 101111_2$, $4AF_{16} = 0100\,1010\,1111_2 = 1199$.
- $2^{10} \approx$ 1천(kilo), $2^{20} \approx$ 1백만(mega), $2^{30} \approx$ 10억(giga), $2^{32} \approx$ 43억.
- MSB는 가장 왼쪽(가장 큰 자리) 비트, LSB는 가장 오른쪽 비트, 니블은 4비트, 바이트는 8비트다.
- 부호 없는 N비트의 범위는 $[0, 2^N - 1]$이다.

### 2. 부호 있는 정수

| 방식 | 음수 표현 | N비트 범위 | 특징 |
|---|---|---|---|
| 부호-크기 | MSB만 1로 | $[-(2^{N-1}-1), 2^{N-1}-1]$ | 0이 두 개(+0, −0), 일반 덧셈 회로로 더하면 틀림 |
| 2의 보수 | 모든 비트 반전 후 1 더하기 | $[-2^{N-1}, 2^{N-1}-1]$ | 0이 하나, 덧셈 회로를 그대로 사용 |

- 4비트 예: $+6 = 0110$, 부호-크기 $-6 = 1110$, 2의 보수 $-6 = 1010$.
- 2의 보수 덧셈은 맨 앞에서 넘친 자리올림을 버린다.
- 오버플로: 부호가 같은 두 수를 더했는데 결과 부호가 다르면 넘친 것이다. $0111 + 0010 = 1001$은 $7 + 2$가 $-7$이 된 경우다.

### 3. 고정소수점 연산

- 소수점 위치를 고정해 정수 회로로 계산한다. 덧셈과 뺄셈은 소수점을 맞춘 정수 연산과 같고, 곱셈은 두 수의 소수 비트 수가 더해진다.
- 연산 비용은 덧셈과 뺄셈 ≪ 곱셈 ≪ 나눗셈이다. 비트 수가 늘수록 곱셈과 나눗셈의 지연과 면적이 크게 는다.

### 4. 부동소수점과 IEEE 754

- 표현: $F = (-1)^S \times M \times \beta^E$. 지수는 바이어스를 더해 저장한다: 저장값 $= E_{true} + \mathrm{bias}$.
- 바이어스를 쓰면 지수를 부호 없는 수처럼 크기 비교할 수 있다.

| 형식 | 부호/지수/가수 비트 | 바이어스 | 대략의 범위 | 해상도 |
|---|---|---|---|---|
| 단정밀도(FP32) | 1 / 8 / 23 | 127 | $2^{128} \approx 3.4 \times 10^{38}$ | $2^{-23} \approx 10^{-7}$ |
| 배정밀도(FP64) | 1 / 11 / 52 | 1023 | $2^{1024} \approx 10^{308}$ | $2^{-52} \approx 10^{-16}$ |

- 정규화 수는 $1.f$ 형태라 맨 앞 1을 저장하지 않는다(숨은 비트).
- FP32 저장 지수 1~254가 정규화 수이고 실제 지수는 −126~127이다.

| 저장 지수 | 가수 $f = 0$ | 가수 $f \ne 0$ |
|---|---|---|
| 0 | ±0 | 비정규화 수(0 근처의 아주 작은 값) |
| 255 | ±∞ | NaN |

- 예: $-6.5 = -110.1_2 = -1.101_2 \times 2^2$ → 부호 1, 저장 지수 $2 + 127 = 129$, 가수 $101000\ldots$ → `0xC0D00000`.
- 지수가 표현 범위를 넘으면 오버플로(±∞), 너무 작으면 언더플로(0이나 비정규화 수)다.
- 반올림 방식 중 가장 가까운 짝수로의 반올림이 기본(필수)이다.
- 덧셈과 뺄셈: 지수를 큰 쪽에 맞추고(작은 쪽 가수를 오른쪽으로 이동) 가수를 더한 뒤 정규화와 반올림을 한다. 곱셈: 부호는 XOR, 지수는 더하고 바이어스를 한 번 빼며 가수는 곱한다. 나눗셈: 지수를 빼고 바이어스를 더한다.

### 5. AI에서 쓰는 수 형식

| 형식 | 부호/지수/가수 | 특징 |
|---|---|---|
| FP32 | 1 / 8 / 23 | 기본 학습 형식 |
| FP16 | 1 / 5 / 10 | 메모리 절반, 표현 범위가 좁아 넘치기 쉬움 |
| BF16 | 1 / 8 / 7 | FP32와 같은 범위, 정밀도는 낮음 |
| INT8, INT4 | 정수 | 양자화 추론. 메모리와 연산을 크게 줄임 |

### 6. 모델 경량화가 필요한 이유

- 모델 크기와 학습 비용과 전력이 빠르게 늘고, 온디바이스 서비스는 지연과 메모리 제약이 있다.
- 대표 기법: 양자화(정밀도 축소), 가지치기(불필요한 가중치 제거), 지식 증류(작은 모델로 지식 전달), 파라미터 효율적 파인튜닝.
- 모델을 작게 만들어도 하드웨어와 배치 크기에 따라 실제 속도 이득이 없을 수 있다. 목표 하드웨어에서 측정한다.

### 7. 양자화

- 실수를 적은 비트의 정수로 대응시킨다: $q = \mathrm{round}(x / s) + z$, 복원은 $\hat{x} = s(q - z)$. $s$는 스케일, $z$는 영점이다.
- 대칭 양자화는 $z = 0$, INT8이면 $s = \frac{\max \lvert x \rvert}{127}$이다. 비대칭 양자화는 최솟값과 최댓값 구간 전체를 쓴다.

| 방식 | 시점 | 장점 | 단점 |
|---|---|---|---|
| PTQ(학습 후 양자화) | 학습이 끝난 모델에 보정 데이터로 범위만 정함 | 재학습 없음, 빠름. LLM에 현실적 | 낮은 비트에서 정확도 하락 |
| QAT(양자화 인식 학습) | 학습 중 양자화 효과를 흉내 내며 학습 | 정확도 유지가 좋음 | 학습 데이터와 비용 필요 |

| 대상 | 예 | 효과 |
|---|---|---|
| 가중치만(Weight-only) | W4A16 | 메모리 절감. 메모리 대역폭이 병목인 LLM 생성에 유리 |
| 가중치와 활성값 | W8A8 | 정수 행렬곱으로 연산 가속 |
| 혼합 정밀도 | 층마다 다른 비트 | 민감한 층은 높은 비트로 보호 |

```python
s = np.abs(w).max() / 127
q = np.clip(np.round(w / s),
            -127, 127).astype(np.int8)
w_hat = q.astype(np.float32) * s
err = np.abs(w - w_hat).max()
```

- 대칭 INT8의 최대 반올림 오차는 $s / 2$ 이하다.

### 8. 가지치기

| 방식 | 단위 | 장점 | 단점 |
|---|---|---|---|
| 비구조적 | 개별 가중치 | 높은 비율로 제거 가능, 정확도 유지가 쉬움 | 불규칙한 희소 행렬이라 GPU에서 실제 속도 이득이 어려움. CSR 같은 희소 형식과 전용 하드웨어 필요 |
| 구조적 | 채널, 필터, 블록 | 밀집 연산이 남아 GPU에서도 빨라짐 | 제거 비율이 낮고 정확도 손실이 큼 |

- 보통 크기가 작은 가중치부터 제거하고, 제거 후 다시 학습(파인튜닝)해 정확도를 회복한다.
- CNN은 80% 이상 제거해도 정확도 손실이 작은 경우가 많고 LLM은 50% 안팎이 현실적이다.

### 9. 지식 증류

- 큰 선생님 모델의 출력을 작은 학생 모델이 따라 하도록 학습한다.
- 온도 $T$를 넣은 소프트맥스 $\mathrm{softmax}(z / T)$로 부드러운 확률(soft label)을 만든다. 정답 외 클래스 사이의 유사도 정보까지 전달된다.
- 전체 손실 = 학생 손실(정답 라벨과의 교차 엔트로피) + 증류 손실(선생님과 학생의 부드러운 출력 차이).
- 선생님과 학생의 크기 차이가 너무 크면 오히려 학생 성능이 떨어진다. 중간 크기 조교 모델을 거치면(TAKD) 나아진다.

### 10. 파인튜닝과 PEFT

| 방법 | 학습 대상 | 장점 | 단점 |
|---|---|---|---|
| In-context 학습 | 없음(프롬프트만) | 즉시 적용 | 프롬프트 길이 비용, 성능 한계 |
| 전체 파인튜닝 | 모든 가중치 | 도메인 특화 성능이 높음 | 비용이 크고 기존 지식을 잊을 위험 |
| Adapter | 층 사이에 넣은 작은 모듈 | 학습 파라미터가 적음 | 구조가 바뀌어 추론 지연이 생김 |
| Prompt tuning | 입력 앞의 가상 토큰 임베딩 | 매우 가벼움 | 표현력 한계, 성능이 불안정 |
| LoRA | 저랭크 행렬 $A$, $B$ | 적은 파라미터, 병합 후 추론 지연 없음 | 랭크 선택 필요 |

### 11. LoRA와 QLoRA

- 원래 가중치 $W \in \mathbb{R}^{d \times k}$는 고정하고 변화량을 저랭크 곱으로 학습한다: $h = Wx + BAx$, $B \in \mathbb{R}^{d \times r}$, $A \in \mathbb{R}^{r \times k}$, $r \ll \min(d, k)$.
- 학습 파라미터는 $dk$ 대신 $r(d + k)$다. $d = k = 10{,}000$, $r = 8$이면 1억 개 대신 16만 개다.
- $B$를 0으로 초기화해 학습 시작 시 $BA = 0$, 즉 원래 모델과 같은 출력에서 출발한다. 출력 크기는 $\frac{\alpha}{r}$로 조절한다.
- 학습 후 $W + BA$로 병합하면 추가 추론 지연이 없다.
- QLoRA: 원래 모델을 4비트(NF4)로 양자화해 메모리를 줄이고, 그 위에 LoRA 어댑터를 높은 정밀도로 학습한다. 단일 GPU로 큰 모델을 튜닝할 수 있고 성능은 16비트 튜닝과 비슷하다.

```python
d, k, r = 768, 768, 8
full = d * k        # 589,824
lora = r * (d + k)  # 12,288
```

### 12. Unsloth로 하는 PEFT 실습 설정

| 설정 | 뜻 |
|---|---|
| 4비트 로드 | 베이스 모델을 양자화해 메모리를 줄여 불러옴 |
| `r` | 어댑터 행렬의 내부 차원. 크면 표현력이 늘지만 파라미터와 연산도 늘어남. 보통 8, 16, 32 |
| `lora_alpha` | 어댑터 출력의 크기(영향력). 흔히 $2r$ |
| `target_modules` | LoRA를 붙일 층. 보통 어텐션의 쿼리와 키와 값 투영층 |
| 대화 형식 | system과 user와 assistant 역할로 데이터를 정리 |

- 저장은 어댑터만 따로 저장(작고 베이스 모델과 조합)하거나 베이스 모델에 병합(완성 모델 하나, 용량이 큼)한다.

### Part 5 자주 틀리는 포인트

- 부호-크기 방식의 범위는 $-2^{N-1}$부터가 아니다. 그건 2의 보수다.
- BF16은 FP16보다 범위가 넓고 정밀도가 낮다.
- PTQ는 재학습이 필요 없다. 양자화해도 정확도가 그대로라는 보장은 없다.
- 가지치기는 비트 수를 줄이는 것이 아니다(그건 양자화다). 비구조적 가지치기는 GPU에서 바로 빨라지지 않는다.
- LoRA는 원래 가중치를 다시 학습하지 않는다.

### 5. PyTorch 모델과 손실

```python
net = nn.Sequential(
    nn.Linear(13, 16),
    nn.ReLU(),
    nn.Linear(16, 3),
)
loss_fn = nn.CrossEntropyLoss()
opt = torch.optim.Adam(
    net.parameters(), lr=1e-3)
```

| 손실 | 모델 출력 | 정답 |
|---|---|---|
| `CrossEntropyLoss` | (B, C) 점수(logit). 소프트맥스를 넣지 않음 | (B,) 정수(`long`) 클래스 번호 |
| `BCEWithLogitsLoss` | (B, 1) 점수. 시그모이드를 넣지 않음 | (B, 1) 실수 0 또는 1 |
| `MSELoss` | (B, 1) 예측값 | (B, 1) 실수 |

- `CrossEntropyLoss`는 내부에서 소프트맥스를 계산한다. 모델 끝에 소프트맥스를 또 넣으면 학습이 나빠진다. 정답을 원-핫으로 바꾸지 않는다.
- 가중치 감쇠는 `torch.optim.Adam(net.parameters(), lr=1e-3, weight_decay=1e-4)`처럼 최적화 도구에 준다.

### 6. 학습 루프와 기록

```python
history = []
for epoch in range(1, 51):
    net.train()
    for xb, yb in loader:
        opt.zero_grad()
        out = net(xb)
        loss = loss_fn(out, yb)
        loss.backward()
        opt.step()
    va = valid_loss(net)
    history.append({
        "epoch": epoch,
        "valid_loss": va,
    })
```

- 순서: `zero_grad` → 순전파 → 손실 → `backward` → `step`. `zero_grad`를 빼면 기울기가 누적된다.
- 에폭 번호를 1부터 기록하라는 조건이 있으면 `range(1, n + 1)`을 쓴다.

조기 종료:

```python
best, wait = float("inf"), 0
for epoch in range(1, 101):
    va = run_epoch(net)
    if va < best:
        best, wait = va, 0
    else:
        wait += 1
        if wait >= patience:
            break
```

학습률 스케줄러:

```python
from torch.optim.lr_scheduler import (
    StepLR,
)
```

### 7. 평가 모드와 확률


- `max(dim=1)`은 값(`values`)과 위치(`indices`)를 함께 돌려준다.
